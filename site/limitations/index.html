Risks and limitations

Last updated November 13, 2026

My Tasks is free and open source, and ready for use within the limitations below. Please read this page before you rely on it. When you set up My Tasks, you're asked to confirm you've read it.

1. Bugs and features still to come

My Tasks is ready for use, but the features on the Roadmap aren't built yet. Every change is tested, but like any software it can have bugs, including ones that lose or change data.

What to do: save a backup file from time to time (Settings › Backup) and keep it somewhere safe.

2. GitHub account and token

My Tasks has no server or accounts of its own. Your tasks are kept in a secret gist in your GitHub account. A gist is a file stored in your GitHub account; a secret gist isn't listed or searchable, but anyone with its web address can open it, which is why My Tasks encrypts it. So you need a free GitHub account and a personal access token. A token with the gist permission can read and change all of your gists, not only My Tasks'. Each device stores its token in the browser, unencrypted.

What to do: use a GitHub account where that's acceptable, give the token an expiry, such as 90 days, and revoke the token on GitHub if a device is lost.

3. Your passphrase

Your tasks are encrypted with a passphrase you choose. My Tasks doesn't store it or send it anywhere, so it can't be recovered. If you forget it and no device is still connected, your data is lost.

Each change to your gist keeps the older version in the gist's history, including tasks you've since deleted, encrypted with the passphrase in use at the time. Changing your passphrase doesn't re-encrypt them.

What to do: choose a strong passphrase from the start, don't use it anywhere else, and keep it in a password manager. A device that's still connected can set a new one.

4. Editing on two devices

Devices sync through your gist a few seconds after each change. If the same task is changed on two devices before they sync, the later change wins, judged by each device's clock, and the other change is lost. Changes to different tasks on two devices are both kept once each device has synced. A change that hasn't synced yet is only on its device, so it's lost if that device's data is cleared or it is disconnected first.

What to do: let a device sync (the sidebar shows "Synced") before switching to another.

5. Your device's copy

Each device keeps a working copy of your tasks in the browser's storage so it works offline. That copy is not encrypted: anyone who can use your unlocked device can read it.

A backup file you save in Settings › Backup is not encrypted either: anyone who can open it can read your tasks. Restoring one replaces all your tasks, on every device once it syncs, and can't be undone.

What to do: lock your devices, and use Disconnect This Device in Settings before giving one away. Keep backup files somewhere only you can open, and save a backup before you restore one.

6. Safari tabs

In a Safari tab, Safari deletes a site's data after 7 days without use. On iPhone and iPad, the installed app and Safari keep separate copies.

What to do: install My Tasks (Add to Home Screen, or Add to Dock on a Mac). Your tasks are also in your gist.

7. Not possible in a web app

Without a server, My Tasks can't send reminders or notifications. Web apps also can't have widgets, Siri or Shortcuts actions, an Apple Watch app, or a Quick Entry shortcut that works from other apps. There's no sharing lists with other people.

8. Platforms

My Tasks is tuned for Safari on Mac, iPhone and iPad, and for Chrome and Edge. Android works but isn't tested. Firefox can't install web apps. Screen readers and other assistive technology aren't supported yet. English only.

9. No guarantees

My Tasks is provided as is, under the MIT licence, with no warranty and no guaranteed support or availability. Please report problems on GitHub.
