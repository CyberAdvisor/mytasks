Security

Last updated November 13, 2026

How My Tasks protects your tasks, and what it can't protect against. The code is open source, so you can check it yourself.

Encryption

  • Your tasks are encrypted on your device before it is sent to your gist, using the browser's built-in Web Crypto.
  • The key is derived from your passphrase with PBKDF2-SHA-256, 600,000 rounds and a random 16-byte salt.
  • Your tasks are encrypted with AES-256-GCM, with a fresh 12-byte IV every time it's saved. GCM also detects any change to the encrypted file.
  • Each device asks for your passphrase once and keeps the key in a form the browser won't let any script read out. The app doesn't store your passphrase or send it anywhere.
  • Change Passphrase re-encrypts your gist with a new salt. Your other devices then ask for the new passphrase. Older versions of the gist stay in its history, encrypted with the passphrase in use at the time.
  • GitHub can see that your gist exists, its size and when it changes, but not your tasks.

Your GitHub token

  • My Tasks uses a classic personal access token with only the gist permission. That permission covers all of your gists, not only My Tasks'.
  • Each device keeps its token in the browser's storage, unencrypted, and uses it only with GitHub's API.
  • Give the token an expiry, such as 90 days. When it expires, make a new one and use Change Token in Settings › Sync on each device.
  • If a device is lost, revoke its token at github.com/settings/tokens.

The app and this website

  • Both are static files served over HTTPS by GitHub Pages. There is no My Tasks server.
  • A strict Content Security Policy lets the app run only its own scripts, never eval, and connect only to itself and GitHub's gist API. This website may not connect anywhere.
  • Notes are always shown as plain text, never as HTML, so pasted text can't run in the app.
  • Every file read from your gist is checked field by field before it is used, and a file that fails is never applied. The app also checks its own data before uploading it.

What it can't protect against

  • Anyone who can use your unlocked device: each device's working copy is not encrypted.
  • Anyone who has both your token and your passphrase.
  • Malicious browser extensions, or malware on your device.
  • A malicious update to the app. My Tasks runs whatever code is published to mytasks.fyi, so a harmful change to that code, or to GitHub's hosting, could read your tasks once they're decrypted on your device. The code is public, so changes can be checked.
  • Someone with access to your GitHub account deleting your gist. They can't read it without your passphrase.
  • A forgotten passphrase: if no device is still connected, your data is lost.

Reporting a vulnerability

Please report security problems privately, through GitHub's private vulnerability reporting, not in a public issue. Include what you found and how to reproduce it.
